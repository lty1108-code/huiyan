# 野颂慧眼 - 效果分析系统静态预览

这个仓库当前包含「效果分析系统」的静态预览版本，用于单独预览和讨论前端视觉与交互。

## 运行方式

直接打开 `index.html`，或在当前目录启动一个静态服务：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 当前包含

- 概览页顶部筛选栏
- 五个指标切换
- 左侧核心指标卡
- 平台横向对比图
- 多平台趋势图
- 平台品牌 icon 和固定品牌色
- 关键词分析页
- 关键词表现 Top5 与 Top10 弹窗
- 关键词类型表现
- 全平台差异 pill 表格

## 当前不包含

- 后端 API
- 登录系统
- 关键词明细、媒介分析、报告中心、项目设置的完整实现
- 数据库和权限系统
