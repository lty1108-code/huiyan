# 野颂慧眼 - 效果分析系统概览页

这个仓库当前只包含「效果分析系统」的概览页静态版本，用于单独预览和讨论概览页视觉与交互。

## 运行方式

直接打开 `index.html`，或在当前目录启动一个静态服务：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 当前包含

- 概览页顶部筛选栏
- 五个指标切换
- 左侧核心指标卡
- 平台横向对比图
- 多平台趋势图
- 平台品牌 icon 和固定品牌色

## 当前不包含

- 后端 API
- 登录系统
- 其他页面或 Tab 的完整实现
- 数据库和权限系统
